# Security Policy

## Supported Versions

Wraith receives active security updates on the main branch and recent releases.

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2.0 | :x:                |

---

## Reporting a Vulnerability

Security and stability in developer shells are paramount. If you believe you have discovered a vulnerability (such as a prompt injection boundary bypass, terminal escape leakage, exit-code corruption, or secret disclosure), please report it responsibly.

### How to Report
1. **Email:** Send details directly to `ghanshyamjha05@users.noreply.github.com` or open a private security advisory on GitHub.
2. **Details to Include:**
   - Detailed description of the vulnerability.
   - Operating system and shell type (e.g. PowerShell 5.1, pwsh 7, Bash, Zsh).
   - Minimal reproduction command or payload.
   - Impact assessment.

### Response Commitment
- **Initial Acknowledgement:** Within 48 hours.
- **Triage & Assessment:** Within 5 business days.
- **Fix & Advisory:** A patch will be published to `main` and a new release tagged once verified.
